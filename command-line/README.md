A Python command-line tool that counts the lines in a UTF-8 text file.

## Requirements

Python 3.9 or newer. No third-party packages.

## Installation

From the root of this examples collection:

```sh
cd command-line
python --version
```

## Usage

```sh
python line_count.py sample.txt
```

Expected output:

```text
3 lines
```
