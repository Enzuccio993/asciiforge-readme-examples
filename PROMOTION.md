## Short product description

ASCIIForge is a free browser-based toolkit for ASCII text banners, image
conversion and copyable text art. Its GitHub README editor includes font width
checks, three editable project examples, Markdown copy and README.md download.
No account is required. Image conversion runs in the browser.

## Developer community post

I built ASCIIForge to make ASCII banners easier to use in GitHub READMEs.
You can compare fonts against your actual project name, check the column width
and take a banner into a README editor without re-entering it. There are three
editable starter examples and a downloadable collection with runnable Python
projects. I would appreciate feedback on the README workflow and mobile layout.

Try it: https://asciiforge.com/en/ascii-for-github-readme/

## Short social post

Make a GitHub README with an ASCII project banner: choose a font, check its
width, adapt a starter and download README.md. Free, no account required.
