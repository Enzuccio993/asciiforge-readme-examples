A small Python module that turns a title into a URL slug, using only the standard library.

## Requirements

Python 3.9 or newer. No third-party packages.

## Installation

From the root of this examples collection:

```sh
cd python-library
python --version
```

## Usage

```sh
python example.py
```

Expected output:

```text
hello-asciiforge
```
