# ASCIIForge README examples

Three small, runnable Python projects with README banners made with
[ASCIIForge](https://asciiforge.com/en/ascii-for-github-readme/?utm_source=github&utm_medium=referral&utm_campaign=readme_examples).
They demonstrate a simple project, a reusable library and a command-line tool.
The examples need Python 3.9 or newer and no third-party packages.

| Example | Run it from its folder | What it demonstrates |
| --- | --- | --- |
| [Hello Project](simple-project/README.md) | `python hello.py` | A short README with a working first command |
| [Text Slug](python-library/README.md) | `python example.py` | A reusable function and an import example |
| [Line Count](command-line/README.md) | `python line_count.py sample.txt` | A CLI with file input and predictable output |

Download or clone this collection, open one example's folder and follow its
README. On some systems the Python command is `python3` or `py`.

## Make your own

1. Open the [README editor](https://asciiforge.com/en/ascii-for-github-readme/?utm_source=github&utm_medium=referral&utm_campaign=readme_examples).
2. Enter your project name and choose a font. Check the reported column width.
3. Pick a complete starter, then replace the example description and commands.
4. Copy the Markdown or download `README.md`, then preview it on GitHub.

The starter keeps your current banner. Replacing text you already entered
requires confirmation. You can also [make a text banner](https://asciiforge.com/en/text-to-ascii/)
and take it into the README editor with its settings.

ASCII art is decoration: keep project names and instructions in normal Markdown
as well. The editor's banner links contain banner text and settings in the URL;
the README description and command fields are not included in those links.
